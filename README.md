## หัวข้อในสไลด์

| สไลด์ | เนื้อหา |
|---|---|
| 1–2 | ปก · แหล่งข้อมูลและตัวแปร 17 ตัว (ข้อ 1) |
| 3–4 | ภาพรวมข้อมูลไม่สมดุล · สถิติพรรณนา (ข้อ 2) |
| 5–6 | แผนภาพการกระจาย · ตัวแปร duration จำแนกกลุ่ม (ข้อ 3) |
| 7 | แผนภาพกล่องเปรียบเทียบระหว่างกลุ่ม (ข้อ 4) |
| 8–10 | การเลือกตัวแปรด้วย stepwise · Odds Ratio · สมการถดถอย (ข้อ 5–6) |
| 11 | Confusion matrix, Accuracy / Precision / Recall, ROC-AUC (ข้อ 7) |
| 12 | ข้อเสนอแนะเชิงธุรกิจและข้อจำกัด |

ตัวเลขทุกตัวในสไลด์คำนวณใหม่จาก `bank.csv` โดยตรง (Accuracy 89.80% · Recall 28.41% · AUC 0.8696 · McFadden Pseudo-R² 0.263)
